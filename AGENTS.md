# APEX ChatD

Это Windows-приложение для чата Twitch с экранным оверлеем, браузерным источником OBS и очередью озвучивания.

- Для задач по поведению приложения, архитектуре и сборке открой нужный раздел [карты проекта](PROJECT_CONTEXT.md). Начни с указанных там файлов и проследи вызовы, которые затрагивает задача.
- Для пользовательских сценариев и названий настроек используй [README.ru.md](README.ru.md) и [README.md](README.md).
- Если изменение затронуло описанный в карте поток данных, точки входа, формат настроек или команды сборки, актуализируй соответствующий раздел карты вместе с изменением кода.

## Плагины и выпуск

- Контракты SDK и формат пакетов описаны в [Plugins/README.md](Plugins/README.md). Сохраняй стабильные ID плагинов и TTS-провайдеров, по которым приложение восстанавливает настройки и голосовые профили.
- Edge TTS собирается и подписывается в [отдельном репозитории](https://github.com/Tor-del/APEX-ChatD-Plugin-EdgeTTS). Для сборки с Edge TTS используй подписанный ZIP последнего стабильного релиза. [Скрипт импорта](installer/Import-EdgePlugin.ps1) проверяет подпись, хеши и совместимость пакета.
- Для выпуска обнови `Version` в [TwitchChatAgent.csproj](TwitchChatAgent.csproj) и отправь новый совпадающий тег `v<версия>`. [Релизный workflow](.github/workflows/release.yml) публикует оба установщика и соответствующие portable ZIP в одном релизе. Оба варианта включают GitHub Updater. Суффикс `-x64.exe` используется для сборки без Edge TTS, `-edge-tts-x64.exe` — для сборки с плагином.
- GitHub Actions подписывает GitHub Updater секретом `APEXCHATD_PLUGIN_SIGNING_KEY`. Приложение проверяет подписи по [открытому ключу](Assets/plugin-approval-public.pem). Закрытый ключ хранится в секретах GitHub Actions и локально вне репозитория.
